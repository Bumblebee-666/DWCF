# DWCF: Dominance-aware Weak-Modality Compensation Framework

This repository hosts the project materials for DWCF, a framework
for alleviating modality imbalance in multimodal learning.

## Overview

DWCF consists of three main components:

- Counterfactual Modality Dominance Regulation (CMDR)
- Progressive Hard-Sample Focusing (PHSF)
- Distillation-Guided Weak-Modality Compensation (DWMC)

## Benchmarks

The framework is evaluated on:

- CREMA-D
- Kinetics-Sounds
- CMU-MOSI
